Predictor ID {{ (exp.predictor or '—')|upper }}

{% if exp.media_type == 'image' or exp.filename.split('.')[-1].lower() in ['bmp', 'png'] %} The spatial predictor estimates each channel byte as the same channel byte of the left pixel. For pixels in column 0, the prediction is 0. Subtracting the prediction from the actual value yields a residual with lower statistical entropy in smooth image regions. {% else %} The delta predictor estimates each sample as the previous sample in the same channel. De-interleaved channel residuals are then encoded independently. This removes inter-sample correlation in smooth audio signals, concentrating probability mass near zero. {% endif %}
