03

Prediction Stage

Predictor type {{ "Spatial + Inter-frame Delta" if is_vid else ("Left-neighbour (per channel byte)" if is_img else "Delta (previous sample, per channel)") }}
Predictor ID {{ (exp.predictor or '—')|upper }}

{% if is_vid %} The video pipeline applies intra-frame spatial prediction combined with inter-frame temporal differencing across adjacent frames. Residual errors are concentrated near zero, greatly lowering Shannon entropy for subsequent adaptive entropy coding. {% elif is_img %} The spatial predictor estimates each channel byte as the same channel byte of the left pixel. For pixels in column 0, the prediction is 0. Subtracting the prediction from the actual value yields a residual with lower statistical entropy in smooth image regions. {% else %} The delta predictor estimates each sample as the previous sample in the same channel. De-interleaved channel residuals are then encoded independently. This removes inter-sample correlation in smooth audio signals, concentrating probability mass near zero. {% endif %}
